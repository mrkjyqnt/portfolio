# mrkjyqnt

Mark Jay Sarcia Quinto — personal portfolio.

This repo contains:

- `wayfinder/` — the planning map for the portfolio (decisions, tickets, research findings). GitHub Issues track open work; closed tickets live in `wayfinder/tickets/` as commit history.
- The actual portfolio app lives at the **repo root** (Vite + React + Tailwind + shadcn/ui + Motion, dark mode default, deployed to Vercel). Scaffolded by ticket [#30](wayfinder/tickets/30-scaffold-project.md). App source: `src/`, `index.html`, `package.json`, etc.
- `Resume - Quinto.pdf` — the source of truth for name, experience, skills, education, and certificates.

## Stack (locked)

Vite 7 · React 19 · TypeScript · Tailwind v4 · shadcn/ui · Motion (renamed from Framer Motion) · Lucide · Vercel

## Aesthetic target

Dark mode default, motion-driven UX, geometric typography (Space Grotesk / DM Sans / JetBrains Mono), modular component feel. No copying of any external portfolio's content or branding.

## Workflow

The repo follows a wayfinder-style plan: `wayfinder/map.md` is the index, open tickets are GitHub Issues, closed tickets are kept in `wayfinder/tickets/` for history. Pick an issue from the [Issues](../../issues) tab to start work.
